開発ノート

OpenAB をつくる過程の記録です。何を変えたか、なぜ変えたか、そこで何を学んだか。

  • 2026-11-10

    OpenAB Computer 0.10.0 の ui_action をどう試したか

    第 1 段階は macOS のアクセシビリティツリーを読むだけでした。OpenAB Computer 0.10.0 の ui_action でツリーを操作できます。一連の操作をどう試しているか、そしてスクリーンショットの繰り返しと比べた差です。TextEdit の作業一つで、入力トークンは 3,165 から 1,435 に、時間は 1.70 秒から 0.36 秒になりました。

    ノートを読む
  • 2026-11-09

    OpenAB Computer が macOS のアクセシビリティツリーを読めるようになりました

    リモートのデスクトップで、エージェントはどうやって狙ったボタンを正確に押すのか。OpenAB Computer 0.9.0 で、Mac アプリのアクセシビリティツリーを JSON で返す MCP ツール ui_snapshot が加わりました。返す内容、Vercel の Agent Desktop から学んだこと、まだ足りないこと。
