Open Agent Broker

コーディングエージェントを、
自分のインフラで。

コーディングエージェントのためのオープンソースのランタイムとネイティブアプリ。チャットで指示し、ターミナルを引き継ぎ、コンピューターを貸し、GitHub へのアクセスを仲介します。

プロダクトを見る Discord に参加

エコシステム

どれも単体で使えます。組み合わせると一つのループになります。エージェントはサンドボックスに、あなたの手はそのターミナルに、エージェントの手はあなたのコンピューターに。

OpenAB Classic

ACP ブローカー

最初の Open Agent Broker。Discord や Slack で bot をメンションすると（Telegram、LINE、Feishu/Lark、Google Chat、WeCom、Teams は gateway アダプター経由）、stdio JSON-RPC で Kiro、Claude Code、Codex、Gemini、Copilot などの ACP コーディング CLI を動かします。

用途 チームのチャットからコーディングエージェントに指示する。タスクごとに一スレッド。

Rust · Discord · Slack · Gateway

github.com/openabdev/openab

OpenAB PTY

サンドボックスのリモートターミナル

ロックダウンされたコンテナ内のシェルを渡す小さなランタイム。uid 1000、sudo なし、読み取り専用のルートファイルシステム、ホストの認証情報なし。WireGuard の tailnet 越しに、セッションごとのトークンで接続します。

用途 エージェントが作業しているのと同じイメージとワークスペースに入り、残したものをその場で見る。

Rust · Kubernetes · ECS

github.com/openabdev/openab-pty

OpenAB Connect

Mac アプリ

OpenAB PTY のネイティブ Mac クライアント。主要ベンダーのエージェントを、それぞれ自分のインフラ上のサンドボックスで。分割ペイン、音声入力、アプリを終了しても動き続けるセッション。

用途 一台の Mac で多くのコーディングエージェントを動かし、見守る。

macOS · Mac App Store

connect.openab.dev

OpenAB Remote

iPhone アプリ

iPhone を OpenAB Connect 用のプライベートなプッシュ・トゥ・トークのリモコンにします。音声は端末上で文字になり、ターミナルに安全なテキストだけが選んだ Mac のセッションに送られます。

用途 キーボードを打たずに、部屋の向こうからエージェントに話しかける。

iPhone · App Store

connect.openab.dev

OpenAB Computer

自分のコンピューターを MCP ツールに

自分の Mac や Linux マシンで動く薄いデーモン。そのマシンを、別の場所にいるエージェントに MCP サーバーとして公開します。シェル、スクリーンショット、マウス、キーボード、AppleScript、ブラウザー。呼び出しには Tailscale の ID と bearer トークンの両方が必要です。

用途 サンドボックスのエージェントに、自分のマシンで Xcode のビルド、シミュレーター操作、画面確認をさせる。

Swift on macOS · Rust on Linux

github.com/openabdev/openab-computer

openab-sb

スイッチボード

外向きにしか接続できないコンピューター上のツールを、エージェントが使えるようにします。各コンピューターが WebSocket 一本でスイッチボードに接続し、スイッチボードは呼び出し元ごとのデフォルト拒否の許可リストに従って MCP 呼び出しを中継します。ツールは実行せず、何も保存しません。

用途 受信ポートを開けずに、自分のネットワーク内のマシンのブラウザーをクラウドのエージェントに貸す。

Rust · MCP · WebSocket

github.com/openabdev/openab-sb

octobroker

GitHub 認証情報ブローカー

エージェントは GitHub の認証情報を一切持たずに、GitHub の MCP ツール、REST と GraphQL の読み取り、さらに git push まで使えます。octobroker は失効可能なキーでエージェントを確認し、デフォルト拒否のツール・リポジトリポリシーを適用したうえで、短命でリポジトリ限定の GitHub App トークンを発行します。

用途 多数のエージェントに、範囲を絞れて、監査でき、取り消せる GitHub アクセスを与える。

Rust · Kubernetes · ECS

github.com/openabdev/octobroker
