Open Agent Broker

OpenAB is an open-source community
that loves freedom and openness.

We build a secure, private, reliable runtime for coding agents, using the subscriptions you already have, on your own computers and servers.

Join Discord GitHub

Community projects

Each piece works on its own. Together they make one loop: an agent in a sandbox, your hands in its terminal, its hands on your computer.

OpenAB Classic

ACP broker Open source

The original Open Agent Broker. Mention a bot in Discord or Slack (or Telegram, LINE, Feishu/Lark, Google Chat, WeCom and Teams through gateway adapters) and it drives an ACP coding CLI such as Kiro, Claude Code, Codex, Gemini or Copilot over stdio JSON-RPC.

For instructing coding agents from team chat, one thread per task.

Rust · Discord · Slack · Gateway

github.com/openabdev/openab

OpenAB PTY

Sandboxed remote terminal Open source

A small runtime that hands out a shell inside a locked-down container: uid 1000, no sudo, a read-only root filesystem and no host credentials. It is reached over a WireGuard tailnet with per-session tokens.

For attaching to the same image and workspace your agent works in, and looking at what it left behind.

Rust · Kubernetes · ECS

github.com/openabdev/openab-pty

OpenAB Connect

Mac app App Store

The native Mac client for OpenAB PTY. Agents from every major vendor, each in its own sandbox on your own infrastructure, with split panes, voice input and sessions that keep running after you quit the app.

For running and watching many coding agents from one Mac.

macOS · Mac App Store

connect.openab.dev

OpenAB Remote

iPhone app App Store

Your iPhone becomes a private push-to-talk remote for OpenAB Connect. Speech is transcribed on the device, and only terminal-safe text is sent to the selected Mac session.

For talking to your agents from across the room instead of typing.

iPhone · App Store

connect.openab.dev

oab-computer

Your computer as MCP tools Open source

A thin daemon on a Mac or Linux box you own that exposes it to an agent elsewhere as MCP servers: shell, screenshots, mouse, keyboard, AppleScript and a browser. Every call needs both a Tailscale identity and a bearer token.

For letting a sandboxed agent build in Xcode, drive the Simulator and check the screen on a machine you own.

Swift on macOS · Rust on Linux

github.com/openabdev/openab-computer

oab-sb

Switchboard Open source

Lets agents use tools on computers that can only dial out. Each computer dials the switchboard over one WebSocket, and the switchboard relays MCP calls to it under a deny-by-default allowlist per caller. It runs no tools and stores nothing.

For lending the browser on a machine in your own network to cloud agents without opening an inbound port.

Rust · MCP · WebSocket

github.com/openabdev/openab-sb

octobroker

GitHub credential broker Open source

Agents get GitHub's MCP tools, REST and GraphQL reads, and even git push without holding a GitHub credential. octobroker checks each agent's revocable key against a default-deny tool and repo policy, then mints short-lived, repo-scoped GitHub App tokens.

For giving a fleet of agents GitHub access you can scope, audit and revoke.

Rust · Kubernetes · ECS

github.com/openabdev/octobroker

oab-nearpush

Desk display for agent status Private preview

Turns an iPhone into a dedicated desk display for your coding agent, one large card at a time: “allow.” when it needs permission, “your turn.” when it is waiting for your answer, “all set.” when the task is done. A small Mac app and daemon feed it from agent hooks on your private network: Kiro today, adapters for other CLIs planned.

For knowing at a glance whether your agent needs you, without watching the terminal.

iPhone · macOS · Kiro hooks
