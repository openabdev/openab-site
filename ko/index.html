Open Agent Broker

OpenAB는 자유와 개방을 사랑하는
오픈소스 커뮤니티입니다.

안전하고, 프라이버시를 지키고, 믿을 수 있는 코딩 에이전트 실행 환경을 만듭니다. 이미 가진 구독으로, 내 컴퓨터와 서버에서.

Discord 참여 GitHub

커뮤니티 프로젝트

각각 따로 쓸 수 있습니다. 함께 쓰면 하나의 루프가 됩니다. 에이전트는 샌드박스에, 내 손은 그 터미널에, 에이전트의 손은 내 컴퓨터에.

OpenAB Classic

ACP 브로커 오픈소스

최초의 Open Agent Broker. Discord나 Slack에서 bot을 멘션하면(Telegram, LINE, Feishu/Lark, Google Chat, WeCom, Teams는 gateway 어댑터로) stdio JSON-RPC로 Kiro, Claude Code, Codex, Gemini, Copilot 같은 ACP 코딩 CLI를 구동합니다.

용도 팀 채팅에서 코딩 에이전트에게 지시하기. 작업마다 스레드 하나.

Rust · Discord · Slack · Gateway

github.com/openabdev/openab

OpenAB PTY

샌드박스 원격 터미널 오픈소스

잠긴 컨테이너 안의 셸을 내주는 작은 런타임. uid 1000, sudo 없음, 읽기 전용 루트 파일시스템, 호스트 자격 증명 없음. WireGuard tailnet을 통해 세션별 토큰으로 접속합니다.

용도 에이전트가 일하는 바로 그 이미지와 워크스페이스에 들어가, 남긴 것을 그 자리에서 보기.

Rust · Kubernetes · ECS

github.com/openabdev/openab-pty

OpenAB Connect

Mac 앱 App Store

OpenAB PTY의 네이티브 Mac 클라이언트. 주요 벤더의 모든 에이전트를 각자의 샌드박스에서, 내 인프라 위에서. 분할 창, 음성 입력, 앱을 종료해도 계속 실행되는 세션.

용도 Mac 한 대에서 여러 코딩 에이전트를 실행하고 지켜보기.

macOS · Mac App Store

connect.openab.dev

OpenAB Remote

iPhone 앱 App Store

iPhone을 OpenAB Connect용 개인 푸시 투 토크 리모컨으로 바꿉니다. 음성은 기기에서 텍스트로 바뀌고, 터미널에 안전한 텍스트만 선택한 Mac 세션으로 전송됩니다.

용도 타이핑 대신 방 건너편에서 에이전트에게 말하기.

iPhone · App Store

connect.openab.dev

oab-computer

내 컴퓨터를 MCP 도구로 오픈소스

내가 소유한 Mac이나 Linux 기기에서 도는 얇은 데몬. 그 기기를 다른 곳의 에이전트에게 MCP 서버로 제공합니다. 셸, 스크린샷, 마우스, 키보드, AppleScript, 브라우저. 모든 호출에 Tailscale 신원과 bearer 토큰이 둘 다 필요합니다.

용도 샌드박스의 에이전트가 내 기기에서 Xcode 빌드, 시뮬레이터 조작, 화면 확인을 하게 하기.

Swift on macOS · Rust on Linux

github.com/openabdev/openab-computer

oab-sb

스위치보드 오픈소스

바깥으로만 연결할 수 있는 컴퓨터의 도구를 에이전트가 쓸 수 있게 합니다. 각 컴퓨터가 WebSocket 하나로 스위치보드에 접속하고, 스위치보드는 호출자별 기본 거부 허용 목록에 따라 MCP 호출을 중계합니다. 도구를 실행하지 않고 아무것도 저장하지 않습니다.

용도 인바운드 포트를 열지 않고 내 네트워크 안 기기의 브라우저를 클라우드 에이전트에게 빌려주기.

Rust · MCP · WebSocket

github.com/openabdev/openab-sb

octobroker

GitHub 자격 증명 브로커 오픈소스

에이전트는 GitHub 자격 증명을 전혀 갖지 않고도 GitHub의 MCP 도구, REST와 GraphQL 읽기, git push까지 씁니다. octobroker는 취소 가능한 키로 에이전트를 확인하고 기본 거부 도구·저장소 정책을 적용한 뒤, 수명이 짧고 저장소로 범위가 제한된 GitHub App 토큰을 발급합니다.

용도 여러 에이전트에게 범위를 좁히고, 감사하고, 취소할 수 있는 GitHub 접근 주기.

Rust · Kubernetes · ECS

github.com/openabdev/octobroker

oab-nearpush

에이전트 상태 데스크 디스플레이 비공개 프리뷰

iPhone을 코딩 에이전트 상태 전용 데스크 디스플레이로 바꿉니다. 한 번에 큰 카드 한 장: 권한이 필요하면 “allow.”, 내 답을 기다리면 “your turn.”, 작업이 끝나면 “all set.”. 작은 Mac 앱과 데몬이 내 사설 네트워크에서 에이전트 hook으로 상태를 보냅니다. 지금은 Kiro를 지원하고, 다른 CLI용 어댑터를 계획하고 있습니다.

용도 터미널을 지켜보지 않아도 에이전트가 나를 기다리는지 한눈에 알기.

iPhone · macOS · Kiro hooks
