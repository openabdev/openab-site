OpenAB Classic

ACP broker 開源

最初的 Open Agent Broker。在 Discord 或 Slack 提及 bot（Telegram、LINE、飛書/Lark、Google Chat、企業微信與 Teams 走 gateway adapter），它就透過 stdio JSON-RPC 驅動 Kiro、Claude Code、Codex、Gemini、Copilot 等 ACP coding CLI。

用途 在團隊聊天室指揮 coding agent，一個任務一個討論串。

Rust · Discord · Slack · Gateway

github.com/openabdev/openab

OpenAB PTY

沙箱遠端終端機 開源

一個小型 runtime，在鎖死的容器裡交給你一個 shell：uid 1000、沒有 sudo、唯讀的根檔案系統、沒有主機憑證。透過 WireGuard tailnet 連線，每個 session 各自一組 token。

用途 進到 agent 工作的同一個 image 和 workspace，直接看它留下了什麼。

Rust · Kubernetes · ECS

github.com/openabdev/openab-pty

OpenAB Connect

Mac App App Store

OpenAB PTY 的原生 Mac 客戶端。所有頂尖廠商的 Agent，各自沙箱，執行在你的私有基礎架構；分割窗格、語音輸入，關掉 app 後 session 繼續執行。

用途 在一台 Mac 上同時執行、觀看多個 coding agent。

macOS · Mac App Store

connect.openab.dev

OpenAB Remote

iPhone App App Store

把 iPhone 變成 OpenAB Connect 的私人按住說話遙控器。語音只在手機上轉成文字，只有可以安全送進終端機的文字會送到選定的 Mac session。

用途 不用打字，在房間另一頭就能跟 agent 說話。

iPhone · App Store

connect.openab.dev

oab-computer

把你的電腦變成 MCP 工具 開源

一個跑在你自己的 Mac 或 Linux 機器上的輕量常駐程式，把這台機器以 MCP server 的形式提供給別處的 agent：shell、截圖、滑鼠、鍵盤、AppleScript 和瀏覽器。每次呼叫都要同時通過 Tailscale 身分與 bearer token。

用途 讓沙箱裡的 agent 在你自己的機器上用 Xcode 編譯、操作 Simulator、檢查畫面。

Swift on macOS · Rust on Linux

github.com/openabdev/openab-computer

oab-sb

交換機（Switchboard） 開源

讓 agent 使用只能主動往外連的電腦上的工具。每台電腦用一條 WebSocket 連上交換機，交換機再依每個呼叫者「預設拒絕」的允許清單轉送 MCP 呼叫。它不執行工具，也不儲存任何東西。

用途 不開任何對內 port，就把你自家網路裡那台機器的瀏覽器借給雲端 agent。

Rust · MCP · WebSocket

github.com/openabdev/openab-sb

octobroker

GitHub 憑證代管 開源

agent 不用持有任何 GitHub 憑證，也能使用 GitHub 的 MCP 工具、REST 與 GraphQL 讀取，甚至 git push。octobroker 以可撤銷的金鑰比對每個 agent「預設拒絕」的工具與 repo 政策，再發放短效、限定 repo 的 GitHub App token。

用途 給一整批 agent 可限縮、可稽核、可撤銷的 GitHub 權限。

Rust · Kubernetes · ECS

github.com/openabdev/octobroker

oab-nearpush

Agent 狀態桌面顯示器 私有預覽

把 iPhone 變成桌上專門顯示 coding agent 狀態的螢幕，一次只顯示一張大卡片：需要權限時是「allow.」，等你回答時是「your turn.」，任務完成時是「all set.」。由一個小型 Mac App 與常駐程式在你的私有網路上從 agent hooks 推送狀態：目前支援 Kiro，其他 CLI 的 adapter 規劃中。

用途 不用盯著終端機，瞄一眼就知道 agent 是不是在等你。

iPhone · macOS · Kiro hooks
