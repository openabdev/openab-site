  • 2026-11-10

    我們怎麼測試 OpenAB Computer 0.10.0 的 ui_action

    第一階段只能讀 macOS 的 accessibility tree，OpenAB Computer 0.10.0 的 ui_action 讓 agent 可以直接操作它。這篇說明我們怎麼測整個操作過程，以及它比截圖迴圈省多少：在一個 TextEdit 任務上，輸入 token 從 3,165 降到 1,435，時間從 1.70 秒降到 0.36 秒。

  • 2026-11-09

    OpenAB Computer 開始支援 macOS 的 accessibility tree

    Agent 是怎麼在遠端電腦上精準點到那顆按鈕的？OpenAB Computer 0.9.0 新增 ui_snapshot，一個把 Mac app 的 accessibility tree 以 JSON 回傳的 MCP 工具。它回傳什麼、我們從 Vercel 的 Agent Desktop 學到什麼，以及還缺什麼。
